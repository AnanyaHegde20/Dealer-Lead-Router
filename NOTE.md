# Note — what I would build next for our dealers

If I joined, I would build in this order. **First, real-time new-lead
notifications:** a Cloud Function that messages the assigned dealer on
WhatsApp or SMS the moment a lead lands. Dealers lose deals in the gap
between a website form and a manual check; a ping within seconds is the
cheapest revenue protection we have. **Second, response-time tracking with
escalation:** log first-contact per lead and auto-escalate anything
untouched after a set window back to In-house Sales, so no dealer silently
drops work. **Third, a dealer performance view** — leads received vs
converted, average response time, by pincode prefix — so coaching and
incentives run on evidence instead of anecdotes. **Finally, cross-source
duplicate handling:** merge the same customer arriving via voice call,
WhatsApp and web into one lead, preventing double assignment and awkward
repeat pitches. Notifications first: small effort, immediate, measurable
impact on conversion.
